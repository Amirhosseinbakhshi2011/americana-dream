# 🇺🇸 Americana Dream

**A vintage American-style website**

Classic Americana aesthetic — cream paper background, navy & red, bold typography, Route 66 spirit, and the old-school American Dream.

Built for Amirhossein Bakhshi.

---

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion

---

## Run

```bash
git clone https://github.com/Amirhosseinbakhshi2011/americana-dream.git
cd americana-dream
npm install
npm run dev
```

Open http://localhost:3000

---

## Design

- Aged cream paper feel
- Strong navy + red stripes
- Serif display typography
- Distressed, confident, classic American energy
- English-first
